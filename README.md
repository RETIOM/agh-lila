# LILA - Light Intermediate Language Architecture
- Tomasz Idźkowski - idzkowskit@student.agh.edu.pl
- Maksymilian Koleśniak - mkolesniak@student.agh.edu.pl

## Temat
Kompilator własnego języka programowania do kodu assembly.

## Opis
Głównym celem projektu jest zaprojektowanie oraz implementacja kompilatora dla autorskiego języka programowania. Proces kompilacji został podzielony na etapy i opiera się na autorskiej reprezentacji pośredniej **LILA (Light Intermediate Language Architecture)**. Kompilator najpierw przeanalizuje kod źródłowy i przetłumaczy go na lekką architekturę LILA, z której następnie wygeneruje zoptymalizowany kod wynikowy niskiego poziomu (assembly).
## Implementacja
`Python 3.14`
